## ทำไมคำถามตรง PDF แต่ยังแปลไม่ได้?

**การค้นข้อมูลกับการแปลเป็นคนละขั้นตอน** หากคำถามเป็นภาษาอังกฤษตรงกับชื่อหัวข้อ Dataset ก็ยังเป็นข้อความภาษาอังกฤษ ไม่ได้มีคำแปลไทยกำกับทุก Chunk

- **Toggle เปิดเป็นค่าเริ่มต้น**: ระบบแสดงคำแปลไทยเมื่อมีคำแปลที่ตรวจไว้หรือ Gemini แปลสำเร็จ (ผู้ใช้ปิดได้เพื่ออ่านอังกฤษต้นฉบับ) การแปลเรียกเฉพาะส่วนของคำตอบที่กำลังมองเห็น
- **ไม่มี Gemini API key**: เปิด Toggle แปลไทยได้ แต่จะใช้คำแปลที่ผูกกับต้นฉบับในเครื่องได้เฉพาะบาง Chunk ส่วนอื่นแสดงอังกฤษพร้อมเหตุผล
- **429 / 503 / 504**: ผู้ให้บริการหรือโควตาใช้งานไม่ได้ แม้ Retrieval สำเร็จและมี Citation ถูกต้อง
- **เลข สูตร เครื่องหมาย**: ระบบใช้ `⟦KEEP_N⟧` ป้องกันตัวเลขและสูตร หากโมเดลทำ Marker หาย สลับลำดับ หรือเปลี่ยนตัวเลข จะปฏิเสธคำแปลเพื่อรักษาความถูกต้อง
- **ชนิด Chunk**: โค้ด ตาราง สูตร ป้ายภาพ และข้อความจาก PDF ที่มีกลิฟไม่แน่นอน ตั้งใจคงต้นฉบับเพื่อไม่ให้ข้อมูลเสีย
- **ผลแปลที่เคยผิดพลาดใน Session**: ระบบเก็บสถานะแปลไว้เพื่อลด API ซ้ำ หากแปลครั้งแรกไม่สำเร็จ ต้องกด **ลองแปลข้อความที่ยังไม่สำเร็จอีกครั้ง** หลังบริการกลับมาทำงาน

### สิ่งที่ปรับปรุง

- เพิ่ม **คำแปลไทยในเครื่องแบบ Source-locked** สำหรับ 16 Chunk ยอดนิยม ได้แก่ หลักการอัลกอริทึม บทนำ Bubble Sort การทำงาน Bubble, Insertion, Merge และ Counting รวมถึงขั้น Divide/Conquer/Combine และย่อหน้า Time Complexity ของ Bubble กับ Merge ที่มีสูตร คำแปลใช้ได้เฉพาะเมื่อ SHA-256 ของข้อความต้นฉบับตรงกับที่ตรวจไว้เท่านั้น หาก Dataset เปลี่ยนจะไม่ใช้คำแปลเก่า
- เพิ่มเหตุผลสถานะการแปลให้แยก **API ไม่พร้อม**, **ไม่มีผู้ให้บริการ**, **ข้อความหรือเลขถูกเปลี่ยน**, **โค้ด/สูตรต้องคงต้นฉบับ** และ **อักขระ PDF ไม่แน่นอน**
- เพิ่มปุ่มแปลใหม่เฉพาะ Chunk ที่แปลไม่สำเร็จ โดยไม่ล้างคำตอบหรือหลักฐาน PDF ที่ค้นพบแล้ว
- ยังคงไม่แต่งข้อมูลจากภายนอก Dataset และไม่ส่งคำแปลที่ไม่ผ่านการตรวจ Marker/ตัวเลขไปแสดงว่าแปลสำเร็จ

## การตอบภาษาไทยและการแสดงผลล่าสุด

- **แปลไทยเปิดเป็นค่าเริ่มต้น** แม้ผู้ใช้พิมพ์คำถามเป็นอังกฤษ เช่น `What is Bubble Sort?` และเปิดอ่านคำแปลในเครื่องได้แม้ใช้ Fallback API Key อย่างเดียวหรือยังไม่มี Gemini Key
- **Bubble Sort คืออะไร** ใช้คำนิยามหน้า 34 หนึ่งย่อหน้า ไม่แสดงคำอธิบายทิศทางการสแกนที่ยาวเกินคำถาม ส่วน `Bubble Sort ทำงานอย่างไร` เพิ่มหลักการหน้า 36 ให้ครบ
- **Merge Sort** ดึงบทนำและขั้น Divide/Conquer/Combine หน้า 72 (แทนการหยุดที่ประโยคว่า 'it operates as follows')
- **Counting Sort** มีนิยามและตัวอย่างการวางค่าที่ตำแหน่งผลลัพธ์ หน้า 90
- **เปรียบเทียบ Bubble Sort กับ Merge Sort** แสดงตารางสั้น ๆ ของหลักการและเวลา ที่รองรับโดยหน้า 34, 40, 72, 78 จากนั้นให้เปิดหลักฐานต้นฉบับได้ ไม่ดึง Algorithm ตัวอื่นเป็นหลักฐานแยก
- แก้สตริงขึ้นย่อหน้าในคำแปล Source-locked จากตัวอักษร `\\n\\n` ให้เป็นการขึ้นบรรทัดจริง และเพิ่มคำแปลที่ตรวจ Hash ของสูตร `Theta(n^2)` กับ `Θ(n lg n)`
- ระบบ fallback ยังคงแสดงข้อความอังกฤษพร้อมเหตุผลเมื่อไม่มีคำแปลในเครื่องและ API 503/429 ไม่สามารถแปลได้ (ไม่รับประกันภาษาไทยครบทุก 868 Chunks)

## ขอบเขตที่ยังต้องทดสอบกับบริการจริง

ชุดทดสอบจำลองการใช้งานแบบ Offline และข้อผิดพลาด 503 ไม่ใช่ผลยืนยันว่าระบบแปลจาก Gemini จริงได้ทุกย่อหน้า คำถามที่ซับซ้อน เช่น มีอาร์เรย์ใหม่ เงื่อนไขการเรียงเฉพาะ อธิบายเหตุผลเชิงลึก หรือเปรียบเทียบประสิทธิภาพภายใต้ข้อจำกัดพิเศษ ยังใช้ Gemini เลือกหลักฐาน และคุณภาพการแปลยังต้องประเมินกับผู้ให้บริการจริงเมื่อ API/โควตาพร้อม

คำแปลแบบ Source-locked เป็นคำแปลช่วยสอนที่จัดทำในโปรเจกต์ ไม่ควรเรียกว่าได้รับการรับรองจากผู้เชี่ยวชาญหรือเป็นฉบับแปลทางการของหนังสือ
