# Sorty — ค้นหนังสืออังกฤษ ตอบภาษาไทยพร้อมหลักฐาน

แชตบอท Streamlit ใช้ PDF อังกฤษ 100 หน้าเพียงฉบับเดียว ทุกคำถามเข้าที่ Gemini API ก่อนเพื่อเลือกว่าจะดึงข้อความตรง ๆ หรือตีความก่อนค้น คำตอบประกอบจากข้อความจริงใน PDF พร้อมหลักฐาน เปิดการแปลไทยได้ตามต้องการ ไม่มีฐานข้อมูล บัญชีผู้ใช้ หรือการบันทึกบทสนทนาลงไฟล์

## เปิดใช้งาน

```bash
./run.sh
```

เปิด http://127.0.0.1:8502/ หรือเริ่มด้วย Python โดยตรง:

```bash
./venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8502
```

- ถาม `ประสิทธิภาพ`, `Performance`, `Efficiency` หรือ `Bubble Sort ทีละขั้น` ได้
- คำตอบที่มีหลักฐานรวมไม่เกินประมาณ 4,000 ตัวอักษรแสดงต่อเนื่องในครั้งเดียว หากยาวกว่านั้นจึงแบ่งตามขอบเขตหลักฐานเท่าที่จำเป็น โดยไม่ตัดเนื้อหาทิ้ง
- ไม่มีแผง Source Text แยกใต้คำตอบ ปุ่ม **ดูหลักฐาน** เปิดหน้า PDF พร้อมไฮไลต์เมื่อกด และเทียบข้อความต้นฉบับได้ในแผง PDF ข้อความต่อเนื่องในหน้าและหัวข้อเดียวกันรวมเป็นชุด มีปุ่มเดียวและไฮไลต์เป็นบล็อกเดียว
- รูปแสดงเฉพาะภาพจริงที่ตรวจและผูกกับเนื้อหาไว้ หากไม่มีภาพ ระบบยังตอบจากข้อความได้
- ปิดการแปลได้ในเมนูด้านซ้าย คำทักทาย เช่น `ไง` ตอบได้โดยไม่เรียก API

## การค้นหาและค่าใช้จ่าย

Gemini เป็นตัวหลักโดยอัตโนมัติ ทุกคำถามเกี่ยวกับหนังสือผ่านขั้นตีความก่อน แม้เป็นชื่อหัวข้อหรือคำถามที่มีคำว่า Sorting อยู่แล้ว Gemini คืน JSON ระบุ `direct`, `interpret` หรือ `out_of_scope` พร้อมคำค้นอังกฤษและ ID หัวข้อที่มีอยู่จริง ไม่มีปุ่มเปิด/ปิด AI

`direct` ดึงหัวข้อ/ข้อความตรงจาก PDF; คำถามธรรมชาติที่ต้องเลือกช่วงข้อความยังใช้ตัวเลือกหลักฐาน `interpret` ใช้คำค้นที่ Gemini ตีความแล้วค้น BM25 ถ้า Gemini ระบุหัวข้อเฉพาะ จะจำกัดรายการหลักฐานในหัวข้อนั้น จากนั้นให้ Gemini เลือก source IDs/บรรทัดตามคำถามต้นฉบับ ไม่ขยายทั้งหัวข้ออัตโนมัติเพียงเพราะคำค้นที่แปลงได้ตรงกับชื่อหัวข้อ ถ้าต้องใช้หลายหัวข้อ Gemini ส่ง section_id=null ตัวอย่างคำถามไทยเรื่องวัตถุประสงค์ของการเรียน Sorting สามารถตีความไปยัง `Why sorting?` แล้วดึงข้อความจากหน้า 10

ขั้นตีความส่งคำถาม ประวัติคำถามที่ตอบแล้วล่าสุดไม่เกิน 2 ข้อ และสารบัญที่มี ID จริง ไม่ส่ง PDF ทั้งเล่ม คำตอบไม่ใช้ข้อความที่ Gemini แต่งขึ้น ตัวเลขและลำดับอาร์เรย์ต้องตรงคำถามต้นฉบับ และข้อความหลักฐานต้องตรง offsets ใน PDF หาก Gemini ระบุว่าไม่มีหลักฐาน จะไม่เอาคำตอบทั่วไปมาทดแทน การแปลข้อความเป็นขั้นแยกหลังค้น

ใช้ `max_output_tokens=1200` สำหรับตีความ, 1800 สำหรับเลือกหลักฐาน และ 6000 สำหรับแปลข้อความ โดย temperature=0 การตีความเป็นขั้นบังคับเมื่อถามเนื้อหา; หาก key ไม่พร้อมหรือผล JSON ตรวจไม่ผ่าน ระบบแจ้งเหตุขัดข้องและบันทึกเหตุผลที่ไม่เปิดเผย key คำทักทายสั้นที่รู้จักตอบในเครื่องได้

Embeddings เป็นทางเลือกเพิ่มเติม การตีความและเลือกหลักฐานด้วย Gemini ทำงานได้เมื่อไม่มี vector index ดัชนีเก่าไม่ถูกโหลดแทน

โมเดลสนทนาปัจจุบันคือ `gemini-3.1-flash-lite` ตามค่า `GEMINI_MODEL` ใน `.env` หรือ Streamlit Secrets ทางเลือก embeddings ใช้ `gemini-embedding-001`, 768 มิติ, `RETRIEVAL_DOCUMENT`/`RETRIEVAL_QUERY` และตรวจ revision ก่อนใช้ การไม่มี embeddings ไม่ได้รับประกันว่าราคาถูกกว่าในทุกปริมาณใช้งาน ต้องวัดโทเคนและจำนวนคำถามจริง

## ติดตั้งเครื่องใหม่

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
```

ใส่ API key ใน `.env` แล้วเปิดด้วย `./run.sh` ห้ามนำ `.env`, `venv`, `OLD` และ `tmp` ขึ้น GitHub ข้อมูล Runtime คือ `book_data`, `metadata`, `assets/images/en` และดัชนีใหม่ใน `vector_store` เมื่อสร้างสำเร็จ PDF.js เก็บในโครงการ ไม่โหลด CDN ขณะอ่านหลักฐาน

### ตั้งค่า Streamlit Community Cloud

ในหน้าแอป เลือก **Settings → Secrets** แล้ววางค่า TOML นี้ โดยใส่ key หลักและ key สำรองของเจ้าของระบบเอง:

```toml
GEMINI_API_KEY = "ใส่คีย์หลัก"
GEMINI_API_KEY_FALLBACK = "ใส่คีย์สำรอง"
GEMINI_MODEL = "gemini-3.1-flash-lite"
```

ค่า Secrets มีลำดับเหนือ `.env` และตัวแปรระบบเมื่อแอปรันบน Streamlit Cloud; อย่าใส่ key จริงใน GitHub หรือไฟล์ `.env.example`.

## ข้อมูลต้นฉบับและการสร้างใหม่

ใช้ `book_data/Cormen_Basic_Sorting_100_Pages.pdf` เท่านั้น ภายในเล่มมีทั้งข้อความต้นฉบับและส่วน Supplement ที่ติดป้ายไว้ จึงไม่ควรเรียกข้อความทั้งเล่มว่าเป็นต้นฉบับ CLRS ทั้งหมด

เอกสารไทยเก็บนอก Runtime ใน `OLD/english-rebuild-2026-10-13/reference-only/` สำเนาก่อนเปลี่ยนระบบคือ `OLD/english-rebuild-2026-10-13/before-rebuild.tar.gz` ข้อมูลค้นเก่าเก็บใน `retired-runtime/` ใต้โฟลเดอร์เดียวกัน

```bash
venv/bin/python scripts/rescan.py --language=en
# ทางเลือก: ทำเมื่อโควตา embeddings ใช้ได้แล้ว
venv/bin/python scripts/build_vectors.py --language=en
```

การสร้าง vectors ทำต่อจาก checkpoint และเผยแพร่ดัชนีเมื่อครบเท่านั้น การเปลี่ยน PDF ทำให้ hash และ revision เปลี่ยน ต้องตรวจภาพใหม่ก่อนอนุมัติ ไม่ยอมรับ Dataset ไทยเข้าระบบค้น

หัวข้อ `Semantic questions and answers` ที่ผู้จัดทำเพิ่มไว้ 39 จุด ถูกแยกออกจาก chunks สำหรับตอบและสร้าง vectors คงเพียงคำถาม 113 รายการเป็นแนวทางชี้ไปยังหัวข้อจริง ไม่ใช้คำตอบที่แต่งเพิ่มเป็นหลักฐาน และไม่แก้ทับ PDF ต้นฉบับ

## ข้อจำกัดที่ต้องทราบ

- Text layer ของ PDF มีสัญลักษณ์คณิตศาสตร์บางส่วนถอดรหัสผิด ระบบรักษาข้อความเดิม แสดงคำเตือน และเปิด PDF ให้ตรวจ ไม่ให้ AI เดาสูตรแทน
- การแปลตรวจรหัสข้อความ ลำดับ ตัวเลข และส่วนที่ป้องกันไว้ หากไม่ผ่านจะแสดงอังกฤษเดิม โค้ด/ตาราง/สูตรคงต้นฉบับ การตรวจเหล่านี้ไม่ได้พิสูจน์ความหมายการแปลครบ 100%
- การค้นคำถามภาษาพูดที่ยังไม่รู้จักอาจพลาด การทดสอบชุดปัจจุบันไม่ใช่หลักประกันความแม่นยำสำหรับทุกคำถาม
- เปิด AI แล้วคำถาม/ข้อความหลักฐานบางส่วนส่งไป Gemini บทสนทนาเก็บชั่วคราวใน Streamlit session
