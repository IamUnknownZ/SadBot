# Sorty — ค้นหนังสืออังกฤษและตรวจหลักฐานจาก PDF

Sorty เป็นแชตบอท Streamlit สำหรับหนังสืออัลกอริทึมการเรียงลำดับภาษาอังกฤษ 100 หน้า ระบบค้นและแสดงข้อความจาก PDF พร้อมปุ่มเปิดหน้าหลักฐาน ผู้ใช้เลือกแปลคำตอบเป็นภาษาไทยได้ บทสนทนาเก็บเฉพาะใน Streamlit session และไม่มีฐานข้อมูลผู้ใช้

## เปิดใช้งาน

```bash
./run.sh
```

หรือเปิดโดยตรงที่พอร์ต 8502:

```bash
./venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8502
```

เปิด <http://127.0.0.1:8502/>

## ระบบตอบคำถามอย่างไร

ระบบเลือกเส้นทางตามลำดับนี้:

1. คำทักทายสั้นตอบจากข้อความในเครื่อง
2. คำถามที่เตรียมคำตอบไว้ ชื่ออัลกอริทึมตรง ๆ และชื่อหัวข้อที่ตรงกับหนังสือ ใช้เส้นทางในเครื่องก่อนเพื่อให้ตอบเร็ว
3. คำถามใหม่หรือภาษาธรรมชาติให้ Gemini ตีความความหมาย แล้วค้นและเลือกหลักฐานจาก PDF
4. คำตอบประกอบจากข้อความใน PDF เท่านั้น Gemini ไม่ได้แต่งข้อเท็จจริงแทนหนังสือ
5. เมื่อเปิด **แปลคำตอบเป็นภาษาไทย** ระบบใช้คำแปลที่ตรวจแล้วก่อน ส่วนอื่นจึงเรียก Gemini
6. ถ้าการแปลไม่สำเร็จ เช่น ผู้ให้บริการตอบ 503 หรือ 504 ระบบแสดงต้นฉบับอังกฤษ

ถ้า Gemini ไม่พร้อม ระบบยังใช้คำตอบที่ตรวจไว้ ชื่อหัวข้อ ข้อความที่คัดลอกตรง และขั้นตอนอัลกอริทึมที่มีหลักฐานชัดเจนได้ แต่จะไม่เอาผลค้น Keyword/BM25 ที่อาจไม่ตอบคำถามธรรมชาติมาแสดงเป็นคำตอบโดยอัตโนมัติ หากไม่มีหลักฐานที่เลือกอย่างมั่นใจ ระบบจะแจ้งว่าการตีความหรือเลือกหลักฐานไม่พร้อม

คำถามพื้นฐานที่ชัดเจน (นิยาม วิธีทำงาน ความซับซ้อน เสถียรภาพ และการเปรียบเทียบสองวิธี) ใช้แหล่งอ้างอิงที่ตรวจในเครื่องได้โดยตรง ดูชุดคำถาม 83 รูปแบบและตัวอย่างใน `docs/QUESTION_AUDIT_2026-10-14_TH.md` ซึ่งไม่รวมคำถามใหม่ที่มีอาร์เรย์ ตัวเลข หรือเงื่อนไขพิเศษ

การค้นหาแบบ Local-first: คำถามพื้นฐาน คำนิยามที่ชัดเจน และการเปรียบเทียบทั่วไป ใช้หลักฐาน PDF ที่ตรวจตำแหน่งแล้วโดยไม่ต้องเรียก Gemini ทุกครั้ง; คำถามซับซ้อนหรือมีเงื่อนไขยังใช้ Gemini เพื่อเลือกหลักฐาน และถ้าไม่มั่นใจจะไม่เดาคำตอบ

การแปลภาษาไทยเป็นขั้นตอนแยก: Toggle **แปลคำตอบเป็นภาษาไทย** เปิดเป็นค่าเริ่มต้น (ผู้ใช้ปิดเพื่อดูอังกฤษล้วนได้) ข้อความต้นฉบับบางส่วนมีคำแปลในเครื่องที่ผูก Hash แล้ว ส่วนอื่นอาศัย Gemini และอาจล้มเหลวด้วย 429/503 หรือถูกปฏิเสธเมื่อสูตรและตัวเลขเปลี่ยน หากไม่มี API key ก็ยังเปิด Toggle เพื่ออ่านคำแปลในเครื่องได้ แต่ Chunk ที่ยังไม่มีคำแปลจะแสดงอังกฤษ หลัง API กลับมาพร้อม กด **ลองแปลข้อความที่ยังไม่สำเร็จอีกครั้ง** ได้โดยไม่ต้องถามซ้ำ

คำถามนิยามพื้นฐาน เช่น `What is Sorting algorithms`, `What are sorting algorithms?` หรือ `อัลกอริทึมการเรียงลำดับคืออะไร` จะอ่านหลักฐานจริงห้าย่อหน้าแรกของ **1.1 Algorithms หน้า 5** (ความหมายของอัลกอริทึม นิยาม sorting ปัญหา Input/Output และตัวอย่าง) โดยตรง ไม่แสดงเมนูหัวข้อย่อย และไม่ต้องเรียก Gemini แม้ API แจ้ง 503 หัวข้อใหญ่ที่กว้างมากจะเริ่มจากเนื้อหาต้นฉบับ ไม่บังคับเมนูเลือกหัวข้อย่อย

Embeddings เป็นส่วนเสริม ระบบยังค้นหัวข้อ คำสำคัญ และ BM25 ได้เมื่อ vector index ไม่พร้อม

## การแสดงคำตอบและหลักฐาน

- แสดงคำตอบต่อเนื่องไม่เกินประมาณ 4,000 ตัวอักษรต่อส่วน ถ้ายาวกว่านั้นจึงมีปุ่มอ่านส่วนถัดไป
- ปุ่ม **ดูหลักฐาน** เปิดหน้า PDF พร้อมไฮไลต์ตำแหน่งข้อความ
- โค้ด สูตร และตารางคงต้นฉบับ เพื่อไม่ให้การแปลทำลายโครงสร้าง
- รูปแสดงเฉพาะไฟล์ที่ตรวจและผูกกับ Chunk ไว้
- ข้อความที่มีสัญลักษณ์จาก text layer ไม่สมบูรณ์จะแจ้งให้ตรวจหน้า PDF

## ติดตั้งเครื่องใหม่

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
```

ใส่ `GEMINI_API_KEY` และ `GEMINI_API_KEY_FALLBACK` ใน `.env` ห้าม commit `.env`

## ตั้งค่า Streamlit Community Cloud

เปิด **Settings → Secrets** แล้วใส่:

```toml
GEMINI_API_KEY = "ใส่คีย์หลัก"
GEMINI_API_KEY_FALLBACK = "ใส่คีย์สำรอง"
```

ไม่ต้องใส่ `GEMINI_MODEL` เพราะโค้ดตรึงรุ่น `gemini-3.1-flash-lite` ไว้แล้ว

## ข้อมูลต้นฉบับ

Runtime ใช้ `book_data/Cormen_Basic_Sorting_100_Pages.pdf` เท่านั้น เอกสารมีทั้งข้อความต้นฉบับและส่วน Supplement ที่ติดป้ายไว้ จึงไม่ควรกล่าวว่าทุกข้อความเป็นต้นฉบับ CLRS

ไฟล์ภาษาไทยใน `OLD/` ใช้เป็นเอกสารอ้างอิงและไม่ใช่แหล่งคำตอบของ Runtime เพราะ text layer แบ่งคำและย่อหน้าไม่เหมาะกับการแสดงผล

สร้าง Dataset ใหม่ด้วย:

```bash
venv/bin/python scripts/rescan.py --language=en
```

สร้าง embeddings เมื่อ quota พร้อม:

```bash
venv/bin/python scripts/build_vectors.py --language=en
```

## ข้อจำกัด

- คำถามใหม่ยังขึ้นกับความพร้อมของ Gemini และคุณภาพ candidate retrieval
- การตรวจ ID, offsets และตัวเลขไม่ได้รับประกันว่าคำแปลไทยถูกความหมาย 100%
- Text layer ของสูตรบางส่วนต้องตรวจเทียบภาพ PDF
- ผล audit 16 คำถามเป็นชุดตรวจขนาดจำกัด ไม่รับประกันทุกคำถาม
- Vector Search ยังไม่ทำงานจนกว่าจะสร้างครบ 868 vectors และผ่าน revision checks
